Dibangun dengan keamanan sebagai dasar

Halaman ini murni berjalan di peramban Anda — tidak ada server backend yang menyimpan data, sehingga tidak ada basis data atau server untuk diserang. Semua permintaan jaringan dibatasi lewat Content-Security-Policy ke domain uji tepercaya lewat HTTPS, teks dari luar (nama penyedia, lokasi) dirender sebagai teks biasa tanpa pernah dieksekusi sebagai kode, setiap permintaan punya waktu habis otomatis, dan tombol uji dikunci selama pengujian berjalan agar tidak ada permintaan ganda yang menumpuk.

Denyut tidak menyimpan riwayat pengujian atau alamat IP Anda di server mana pun.
